# 🏛️ Petualangan Menjelajahi Kerajaan Nusantara
### Misi Rahasia Sang Arkeolog Muda

Game pembelajaran interaktif **Sejarah Indonesia** untuk **Kelas X SMA (Fase E)**, dengan materi **Kerajaan Hindu-Buddha di Indonesia**. Dibuat dengan HTML5, CSS3, dan JavaScript murni dalam satu file (`index.html`), tanpa framework dan tanpa koneksi internet.

▶ **Main online:** `https://USERNAME.github.io/NAMA-REPOSITORI/` (ganti dengan alamat milik Anda setelah mengikuti langkah di bawah)

## Cerita
Kamu adalah **ARKA**, arkeolog muda yang menemukan artefak kuno pembuka gerbang waktu. Mesin waktunya rusak, sehingga ARKA harus mengumpulkan **lima Fragmen Sejarah** di lima kerajaan agar bisa pulang.

## Tujuan Pembelajaran
1. Menjelaskan perkembangan kerajaan Hindu-Buddha di Indonesia.
2. Mengenali kerajaan beserta peninggalan sejarahnya.
3. Memahami kehidupan sosial, budaya, agama, dan pemerintahan pada masa tersebut.
4. Menghubungkan peninggalan sejarah dengan kerajaan yang meninggalkannya.
5. Berpikir kritis melalui eksplorasi dan pemecahan teka-teki.

## Level
| Level | Kerajaan | Teka-teki |

| 1 | Kutai | Mencocokkan Prasasti Yupa, tokoh, dan keterangannya |

| 3 | Sriwijaya | Mengelompokkan barang dagangan |

| 5 | Majapahit | Menyusun kronologi peristiwa |

## Cara Bermain
- **Bergerak:** tombol panah atau `W` `A` `S` `D` (layar sentuh: tombol arah di layar)
- **Berinteraksi:** tombol `E` di dekat artefak ✨, tokoh, atau stasiun 🧩
- **Jeda:** `ESC` atau tombol ⏸
- Tiap level: temukan 3 artefak → bicara dengan tokoh → selesaikan teka-teki.
- **Skor:** artefak +100, teka-teki +150, misi +200, bicara dengan tokoh +50, petunjuk −10 (maksimal 3500).
- **Gelar akhir:** 90–100% Ahli Sejarah Nusantara • 75–89% Penjelajah Sejarah • di bawah 75% Penjelajah Pemula.

Progres tersimpan otomatis di browser masing-masing murid (`localStorage`).

## Cara Meng-hosting di GitHub Pages (tanpa instalasi)
1. Masuk ke [github.com](https://github.com) dan buat akun jika belum punya.
2. Klik **New repository**, beri nama (misalnya `game-kerajaan-nusantara`), pilih **Public**, lalu **Create repository**.
3. Klik **uploading an existing file**, seret `index.html` dan `README.md`, lalu **Commit changes**. Nama file harus tepat `index.html` (huruf kecil).
4. Buka **Settings → Pages**.
5. Pada **Build and deployment**, pilih **Source: Deploy from a branch**, **Branch: `main`**, folder **`/ (root)`**, lalu **Save**.
6. Tunggu 1–3 menit. Alamat game muncul di bagian atas halaman Pages:
   `https://USERNAME.github.io/NAMA-REPOSITORI/`
7. Bagikan tautan tersebut kepada murid. Mereka dapat memainkannya di laptop maupun HP.

> Setelah itu, ganti `USERNAME` dan `NAMA-REPOSITORI` pada bagian "Main online" di atas dengan alamat sebenarnya (ikon ✏️ pada README di GitHub).

## Menjalankan di Komputer Sendiri
Unduh `index.html`, lalu buka dengan Chrome, Edge, Firefox, atau Safari. Tidak perlu server.

## Memperbarui Game
Pada repositori, buka `index.html`, klik ikon ✏️ (Edit) atau **Add file → Upload files** untuk menimpa dengan versi baru, lalu **Commit changes**. Situs akan diperbarui otomatis dalam beberapa menit.
